
# 🚌 KSRTC Parcel Logistics

### Parcel Booking and Tracking on State Buses

A web-based parcel booking and tracking platform designed to improve parcel visibility between bus stations. The system allows users to book parcels, receive a unique reference number, and track parcel status, while station staff can manage incoming shipments.

---

### Live demo: https://ksrtc-logistics.ai.studio/ ###

## 🚀 Overview

Parcel booking through state buses can involve manual processes and limited tracking visibility. Our prototype aims to simplify this process by connecting senders, receivers, and station staff through a digital tracking system.

With our platform, users can:

- Book parcels between stations.
- Receive a unique parcel reference number.
- Track parcel status using the reference number.
- View parcel progress from booking to arrival.
- Allow station staff to update shipment status.

---

## ✨ Features

### 📦 Parcel Booking
- Book parcels between source and destination stations.
- Enter sender, receiver, and parcel details.
- Generate a unique reference number.

### 🔍 Public Parcel Tracking
- Track parcels using a reference number.
- No login required for public tracking.
- View parcel status and delivery progress.

### 🏢 Station Management
- View incoming parcels.
- Update parcel status through the delivery process.
- Manage shipment information through the station interface.

### 📊 Dashboard
- View recent shipments.
- Check parcel status.
- Access shipment history and tracking information.

## 🔄 How It Works

1. The sender enters parcel and station details.
2. The system generates a unique reference number.
3. The parcel is recorded in the system.
4. Station staff update the parcel's status.
5. The sender or receiver checks progress using the reference number.

---

## 🎯 Problem Statement

Senders and receivers may have limited visibility into the movement of parcels transported between bus stations. This prototype provides a digital way to book parcels and follow their status through a unique reference number.

## 🧪 Current Prototype Status

The prototype demonstrates:

- Parcel booking.
- Reference number generation.
- Public reference-based tracking.
- Station-side status updates.

### Known Limitations

- SMS and WhatsApp notifications are not implemented yet.
- Station authentication and role-based access are pending.
- Online payment is not currently included.
- Receiver OTP/signature verification is pending.
- Bus and conductor details are currently demo-assigned.
